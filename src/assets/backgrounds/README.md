# Continuous Flowerup background

The supplied cream PNG is the visual reference. Built-in image_gen adapted its floral style into a transparent repeat, replacing the rejected mirrored panels. Original files remain untouched.

The app uses flowerup-continuous-repeat.svg, a non-mirrored half-drop repeat embedding flowerup-continuous.webp. Alternate columns shift vertically by half a tile to prevent blank horizontal bands. The WebP is optimized to 640px (92 KB); original generated PNGs remain outside the repo. CSS applies uniform tone-on-tone ink to each existing surface: cream #b39263, yellow #ba8c21, pink #c86c8b, mint #599e8d, orange #cc9556. Original background colours are unchanged. No gradients, centre fades, mirrored sections or overlapping layers. Pattern width: 560px desktop, 440px mobile.

Original page colours: homepage/confirmation/First Bloom #fffdf6; Style #fff4e7; Colours #fff5c9; Frequency #fce4ee; Quantity #d9f0e5; Delivery #fff0d8; Summary #d8eeec; homepage how-section #ffe3eb, benefits #8fd0bf, closing #f8e9e5.
